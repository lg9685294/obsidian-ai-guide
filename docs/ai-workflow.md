# AI 协作

先把知识库的实际路径交给能操作电脑、读写本地文件的 AI，要求它读取 AGENTS.md 与首页，再说明本次需要记录或查找什么。

整理时保留原始内容，区分用户决定、AI 建议和验证结果。新增笔记前查找同题内容，修改时保留来源并更新相关索引。

按日期查看当天记录，按主题查找可复用方法，按项目查看当前进展。AI 返回笔记路径与打开入口，不把示例或未核对的内容当作真实结论。

可以直接说“整理今天的会议”“找会员卡标题参考”“把这段讨论保存到当前项目”。原视频与大型工程保留在稳定位置，先用链接记录；批量删除或替换原文件前确认具体范围。

这个示例库只提供基础目录和协作约定，不包含内置 AI、自动转写或表单插件。能否执行安装与写入，取决于所用助手的能力和授权。
